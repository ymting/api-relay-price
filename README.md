# 中转站比价

把各家 API 中转站的**模型 / 分组 / 价格**抓下来存到本地，按模型归类，点开就能横向比价。
配上账户凭据后，还能看到每个站**充了多少、用了多少、还剩多少**，以及每个分组下**有没有 Key**。

全程本地运行，只用 Python 标准库，不需要 Docker、Node、数据库。

## 它能做什么

- **横向比价**：按模型归类，列出全部「站点 × 分组」报价，最低价高亮；支持按站点 / 计费方式 / 厂商 / 标签筛选，模糊搜索，USD 与人民币切换。
- **账户总览**：一行汇总 + 紧凑站点表，显示余额、已使用、已充值、Key 数量与更新状态，可展开看分组、充值记录、请求次数。
- **模型健康**：读 New API 的 perf-metrics 与 Sub2API 的渠道监控，看成功率、延迟、吞吐量。只读统计，不调模型、不耗额度。
- **Key 管理**：在报价条目里直接创建、复制、删除 Key，一键导入 [CC Switch](https://ccswitch.io) / Cindy，模型名自动换成该站真正认的原始名。
- **定时 + 手动采集**：每天定点跑一次，也可以手动全量或自定义（按站点 × 模型），串行节流，避免被当爬虫。
- **失败不洗数据**：某站这次抓不到就沿用上次结果并打 `stale` 标记；全部失败或中途停止则整轮不写盘。
- **备份还原**：站点与设置导出成一个 JSON，或整份还原；还原前自动归档当前配置。
- **可选访问保护**：单账号登录，口令 scrypt 派生，会话 Cookie + CSRF；服务器模式下没开认证会直接拒绝启动。

## 两步开始

1. **双击 `启动服务.bat`** —— 启动本地服务并自动打开浏览器（服务窗口别关，关了定时任务就没了）。
2. **打开 <http://127.0.0.1:8765>** —— 在「系统设置 → 站点设置」里加站点、填凭据，然后点「手动采集」。

只想看价格、不想开服务：双击 `中转站比价.html` 也行，它只读本地快照。

## 安全底线

这四条是硬约束，改部署文件时也别破：

1. 业务端口只绑 `127.0.0.1`，公网入口交给反向代理；要对外必须配好 `RELAY_ALLOWED_ORIGINS` 与 `RELAY_ALLOWED_HOSTS`。
2. 服务器模式**必须先跑 `--init-auth`**，否则服务以退出码 1 拒绝启动，容器会重启循环。
3. 不要为了让它起来就设 `RELAY_ALLOW_UNAUTHENTICATED_REMOTE=1`，除非前方反代确实做了鉴权。
4. 凭据只存在本机 `sites.json`（已被 `.gitignore` 排除），不进版本库、不进 compose、不进对话。
